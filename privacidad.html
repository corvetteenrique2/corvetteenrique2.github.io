Política de privacidad

Última actualización: 24 de noviembre de 2026.

Qué es esta app

Nido Digital Uploader es una herramienta privada del canal de YouTube Nido Digital. Solo la usa el dueño del canal para subir los videos del propio canal.

Datos de Google que usa

  • YouTube Data API: subir videos al canal propio, leer el nombre del canal para confirmar que es el correcto, cambiar la visibilidad de esos videos y agregarlos a listas de reproducción del mismo canal.
  • No lee, guarda ni comparte datos de otros usuarios, comentarios, correos, contactos ni archivos.

Dónde se guardan

El permiso de acceso se guarda solo en la computadora del dueño del canal. No se envía a servidores de terceros, no se vende y no se usa para publicidad.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Puedes quitar el permiso en cualquier momento desde myaccount.google.com/permissions.
